# Blender Tutorial Resource Index (Public Template)

This public repository ships a clean, structured template for maintaining a graded local Blender tutorial library. Personal bookmark URLs and unverified third-party reposts are intentionally excluded.

## Trust & Freshness Grading

| Grade | Meaning | Usage |
| --- | --- | --- |
| **A** | Official Blender Foundation / Blender Studio / original author channel with verified Blender 4.x/5.x coverage | Primary reference for standard workflows |
| **B** | Reputable community creator with clear topology/node demonstrations and verifiable scene results | Secondary comparison reference |
| **C** | Unverified repost, outdated Blender 2.8/3.x workflow, or missing source attribution | Keep isolated; verify independently before adopting |
