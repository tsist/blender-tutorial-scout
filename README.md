# Blender Tutorial Scout Skill

A portable AI agent skill for checking local Blender tutorial libraries first, scouting high-signal original Blender tutorials when specific techniques are missing, and indexing them with explicit Blender version baselines and trust grades (`A` / `B` / `C`).

> Note: This public repository ships clean, sanitized index templates (`references/resource-index.md` and `references/up-directory.md`) with official Blender references only. Personal bookmarks and unverified third-party reposts are intentionally excluded.

## Installation

```powershell
git clone https://github.com/tsist/blender-tutorial-scout.git ~/.agents/skills/blender-tutorial-scout
```

See [SKILL.md](SKILL.md) and [references/](references/).
